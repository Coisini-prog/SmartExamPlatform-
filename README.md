基于 SpringBoot + Vue 的智能答题考试平台（AI组卷 · 即时答疑 · 主观题自动批改 · PK对战 · 知识图谱 · 反切屏检测） 在线答题考试系统 计算机毕设项目 > 涵盖普通用户、教师、管理员三大角色。   > 核心创新：AI 智能组卷、即时答疑解析、主观题 AI 批改、PK 实时对战、知识图谱可视化、学情诊断与自适应学习路径。   > 技术栈：Spring Boot 3 + MyBatis + MySQL + Elasticsearch + WebSocket + Vue 3 + Element UI + ECharts。

## 创新亮点

本系统在传统在线考试平台基础上，深度融合 AI 技术与教育场景，核心创新包括：

- 🤖 **AI 智能组卷**：用户选择知识点与难度，系统自动生成个性化试卷
- 💬 **即时答疑（AI 解析）**：答题过程中随时获取详细解题步骤与知识点讲解
- 📝 **主观题 AI 批改**：基于语义相似度与逻辑结构进行初步评分并给出改进建议
- ⚔️ **PK 实时对战**：随机匹配或好友房，实时得分同步，沉浸式竞技体验
- 🕸️ **知识图谱自动生成**：每次答题后可视化展示知识点关联网络
- 📈 **AI 学情诊断与自适应学习路径**：通过知识图谱定位薄弱点，动态调整学习策略
- 🔒 **反作弊机制**：切屏检测、A/B卷、选项乱序等多重防护

## 技术栈

### 后端技术栈

- 核心框架：Spring Boot 2.7.18

- UI 组件库：Element UI

- 图表库：ECharts

## 第一层：普通用户（答题者）

### 1. 基础模块

- **注册登录**：支持手机号注册与登录，保障账户安全。
- **个人信息管理**：用户可以修改头像、昵称、密码等基本信息。
- **学习统计**：直观展示用户的学习数据，包括累计学习时长、答题总量、总体正确率、历史趋势图，帮助用户了解自身学习轨迹。
- <img width="1742" height="901" alt="image" src="https://github.com/user-attachments/assets/38f3555f-3dc0-4ba6-8c4d-1279d4f518a5" />


### 2. 智能答题模块

- **AI 组卷**：用户可选择知识点范围和难度，由AI自动生成一套个性化试卷，用于日常巩固或查漏补缺。
- **专项练习**：针对特定章节或知识点（如“三角函数”）进行集中刷题，强化薄弱环节。
- **模拟考试**：提供限时、仿真的考试环境，包含标准题型分布，帮助用户适应正式考试节奏。
- **错题本（AI 推荐同类题）**：自动收录所有答错的题目。系统会根据错题的知识点，智能推荐3-5道同类变式题，供用户针对性攻克。
- **练习模式多样化**：支持顺序练习、随机练习、按题型练习、背题模式（直接看答案），满足不同复习习惯。
- <img width="1813" height="760" alt="image" src="https://github.com/user-attachments/assets/2226f21e-b986-473e-b849-7c799a791bd5" />


### 3. 在线考试交互

- **答题卡导航**：题号网格跳转，已答/未答/标记状态一目了然。
- **倒计时 + 分级提醒**：剩余5分钟、1分钟预警，时间到自动交卷。
- **答案自动保存**：每30秒自动存草稿，防止断电或刷新导致数据丢失。
- **题目标记**：支持“不确定”标记，方便后续复查。
- **成绩详情页**：提交试卷后立即呈现分数、是否及格、答对/答错题明细、错题解析。
- <img width="1768" height="879" alt="image" src="https://github.com/user-attachments/assets/a4716cae-3d99-47eb-97a0-4b013d9e18e0" />


### 4. AI 辅助模块

- **即时答疑（AI 解析）**：用户在答题过程中，可随时点击“AI解析”按钮，获得详细的解题步骤、知识点讲解和相关公式/概念链接。
- **主观题智能批改**：对于简答、论述等主观题，AI能基于关键词、逻辑结构和语义相似度进行初步评分，并提供改进建议，大幅提升批改效率。
- **AI 学情诊断 + 动态自适应学习路径**：用户首次进入做少量测试，AI通过知识图谱快速定位薄弱知识点，生成专属个性化学习路径，并根据每次答题反馈实时调整后续题目难度和推送策略。

### 5. PK 对战模块

- **创建/加入房间**：用户可以创建一个公开或私密的PK房间，设置题目范围、题目数量；也可通过房间号快速加入好友的房间。
- **随机匹配**：一键匹配实力相近（基于积分或正确率）的在线对手，开始一场紧张刺激的对决。
- **实时得分进度**：双方答题界面会同步显示各自的实时得分、剩余时间和当前排名，营造沉浸式竞技感。
- **胜负结算**：PK结束后，系统会公布胜者、双方详细得分对比、用时以及积分变动情况。

### 6. 知识图谱模块

- **答题后自动生成关联知识点图谱**：每次完成答题后，系统会根据本次作答涉及的所有知识点，自动生成一张可视化的网状图谱，清晰展示知识点间的关联关系（如父子、前后置）。
- **点击节点跳转对应题目/讲解**：用户点击图谱上的任意知识点节点，可直接跳转到与该知识点相关的历史错题、经典例题或AI生成的详细讲解页面。

- **排行榜**：设有总积分榜、周榜、学科榜、PK胜率榜等多种维度，激励用户良性竞争。
- **答案点赞评论**：用户可以对他人发布的优质答案解析进行点赞、收藏或发表评论，形成互助学习氛围。

## 第二层：出题者/教师（内容生产者）

### 1. 题库管理模块

- **手动录题**：提供富文本编辑器，支持录入题干、选项、答案、解析、知识点标签、难度等级等全部字段。
- **AI 辅助出题**：输入一段文本或知识点，AI可自动生成选择题、判断题、填空题等多种题型，出题者可在此基础上修改完善。
- **Excel/Word 批量导入**：支持按照预设模板，通过Excel或Word文件一次性导入大量题目，极大提高建库效率。
- **题目查重**：基于 SimHash 等算法检测相似题，避免题库重复。
- **题型扩展**：补全填空、不定项、阅读理解、完形填空等常见题型。
- **题目审核流**：教师提交题目 → 管理员审核 → 进入公共题库。

<img width="1878" height="880" alt="image" src="https://github.com/user-attachments/assets/8c733cf6-eb63-4f64-828b-f7c156b7fffc" />

### 2. 试卷管理模块

- **手动组卷**：从题库中逐题挑选，自由组合成一份试卷，并可调整题目顺序和分值。
- **智能组卷**：设定试卷的总分、难度分布比例（如易30%、中50%、难20%）及各知识点占比，系统自动从题库中抽取最优题目组合生成试卷。
- **A/B 卷**：同一考试生成多套等价试卷，防作弊。
- **试题/选项乱序**：按规则生成试卷时，自动打乱题目顺序和选项顺序。

<img width="1888" height="862" alt="image" src="https://github.com/user-attachments/assets/4b578f19-a4de-405e-b348-bb4606b01faa" />

### 3. PK 管理模块

- **创建自定义 PK 赛**：教师可为班级或特定群体创建专属PK赛，可指定使用的题库、比赛起止时间、参与人数上限（如40人）。
- **查看比赛数据**：PK结束后，教师可查看每场比赛的详细数据，包括每位学生的答题详情、正确率、用时、排名变化等。

### 4. 学情监控模块

- **班级管理**：创建和管理班级，通过邀请码将学生加入班级，便于统一管理。
- **成绩统计**：查看班级整体的平均分、最高/最低分、分数段分布，以及每位学生的历次考试成绩趋势。
- **薄弱点雷达图**：为每位学生或整个班级生成多维度雷达图，直观展示其在各个知识点或能力维度上的掌握程度（如计算能力、空间想象、逻辑推理）。
- **AI 分析报告**：系统自动生成班级学情报告，内容包括高频错题排行、共性薄弱知识点、推荐的教学改进方向等。

<img width="1875" height="860" alt="image" src="https://github.com/user-attachments/assets/f1fedf5e-403e-4f7a-803f-b6e75862a042" />

### 5. 阅卷与批改

- **客观题自动判分**：提交即出分。
- **主观题人工批改**：支持匿名流水判卷（不同题型分配不同教师批改，防作弊）。
- **批改评语**：为整卷或每道题添加评语。

## 第三层：超级管理员（运营者）

### 1. 用户管理模块

- **编辑用户信息**：后台可查询、修改任何用户的基本信息（如重置密码、变更角色）。
- **封禁/解封**：对违反平台规则的账号进行临时或永久封禁处理，并可执行解封操作。

<img width="1858" height="820" alt="image" src="https://github.com/user-attachments/assets/2b36b36a-80ea-49e9-90f4-3f787cc8cd74" />

### 2. 内容审核模块

- **题目审核**：对出题者提交的新题或修改题进行审核，检查内容准确性、合规性，通过后方可进入公共题库。
- **评论审核**：管理社区内的用户评论，删除包含广告、辱骂、敏感信息的违规评论。
- **PK 房间监管**：实时监控正在进行的PK房间，对出现异常行为（如刷分、言语攻击）的房间进行干预或关闭。

<img width="1855" height="745" alt="image" src="https://github.com/user-attachments/assets/30324bc4-cc38-435e-b3e2-7bf58e8274bc" />

### 3. 数据统计模块

- **DAU**：查看每日活跃用户数，分析用户增长和留存趋势。
- **留存率**：统计次日、7日、30日用户留存率，评估平台粘性。
- **热门科目**：统计各学科的答题量、参与人数，识别最受欢迎的科目。
- **PK 参与率**：统计参与过PK的用户占总用户的比例，以及每日PK场次。
- **知识图谱点击热力图**：分析用户点击知识图谱节点的频率，找出最受关注或最难掌握的知识点。
- **Dashboard 数据看板**：ECharts 可视化展示考试总数、用户数量、成绩趋势、题库规模等全局指标。
