# SmartExamPlatform-
基于 SpringBoot + Vue 的智能答题考试平台（AI组卷 · 即时答疑 · 主观题批改 · PK对战 · 知识图谱） 在线答题考试系统  > 一款面向高校计算机毕设的完整全栈项目，涵盖普通用户（答题者）、教师（出题者）、超级管理员三大角色。   > 核心创新：AI 智能组卷、即时答疑解析、主观题 AI 批改、PK 实时对战、知识图谱可视化、学情诊断与自适应学习路径。   > 技术栈：Spring Boot 3 + MyBatis + MySQL + Elasticsearch + WebSocket + Vue 3 + Element UI + ECharts。
